The manifest check is fail-closed: a wrong use_degrees, a changed bus id, a reordered map, or a
missing normalize keyword makes the server exit 2 before it binds the port. Tested headless in
tools/test_units_manifest.py (18 checks) and against the real handler (tools/test_joint_server.py).

What the table proves (joint_units.csv + ros_snapshot.json, 12 rows, arm passive):
  * SDK value  ==  raw tick  -> DEGREES formula (mid = (range_min+range_max)/2, 4095 counts)
                    |delta| = 0.000 deg on all five body joints of both arms;
     jaw: pct = (tick - range_min)/(range_max - range_min) * 100, |delta| = 0.000 %.
  * ROS value  ==  SDK value (|delta| = 0.000): arm_bridge copies the numbers verbatim, so the
     topic carries the same unit the server reports.
  * Calibration hashes above are the ones the numbers were produced against.

  * jaw aperture in mm, both directions (tools/jaw_curve.py), plus hysteresis and deadband.
  * supported signed maintenance moves with the independent stop available.
  * loaded vs unloaded sag, backlash on reversal, soft endpoints under load.
